# המתכונים של מעיין

מגישה: מעיין לזמס

פרויקט בהנדסת תוכנה, שנבנה ב־Android Studio בשפת Java.
בשלב זה האפליקציה כוללת שלושה מסכים:

## מסך פתיחה — Splash
<img width="1600" height="912" alt="splash png3" src="https://github.com/user-attachments/assets/30cba835-d8ad-4884-a44b-b0ab4620b4ff" />

מציג תמונת אפייה עם אנימציה של הופעה הדרגתית ועלייה מלמטה.
לאחר שלוש שניות עובר אוטומטית למסך הכניסה.

## מסך כניסה — Login
<img width="1600" height="902" alt="spalsh png2" src="https://github.com/user-attachments/assets/bf31cf2d-0f02-4184-b86e-b1ea98eeb93e" />

כולל שדות שם משתמש וסיסמה, כפתור כניסה וקישור להרשמה.
מציג הודעה כאשר שדה ריק, הפרטים שגויים או הכניסה הצליחה.

## מסך הרשמה — Register
<img width="1600" height="919" alt="splash png" src="https://github.com/user-attachments/assets/ef8b9561-cde8-4579-bb5c-97551798afd5" />

כולל שם משתמש, סיסמה ואימות סיסמה.
בודק ששם המשתמש אינו ריק, שהסיסמה מכילה לפחות שישה תווים וששתי הסיסמאות זהות.
שגיאות מוצגות ליד השדה המתאים.
בהרשמה תקינה הפרטים מועברים למסך הכניסה באמצעות Intent extras, ללא שמירה בקובץ או במסד נתונים.
